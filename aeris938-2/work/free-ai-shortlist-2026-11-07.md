## กฎตัดสิน (สำคัญที่สุด)

คำว่า "ฟรี" มี 3 ความหมาย ต้องแยกให้ออก ไม่งั้นเจอบิล:

1. **ฟรีจริง** — ดาวน์โหลดมารันเอง ไม่มี API ไม่ต้องบัตร ไม่มีวันหมดอายุ
   (แต่ต้องเช็ค license ของ weights ว่าใช้เชิงพาณิชย์ได้ไหม)
2. **ฟรีแบบมีโควตา** — ใช้บริการออนไลน์ได้ $0 แต่จำกัดคำขอ/ความเร็ว/ปริมาณ
   ต้องปิด billing ไว้ และถือว่าเมื่อเกินโควตา = หยุด ไม่ใช่จ่าย
3. **"ฟรี" ที่กลายเป็นบิล** — มีบัตร, เครดิตทดลอง, หมดอายุ → **ห้ามเข้า production**

AERIS ใช้กลุ่ม 1 เป็นแกน, กลุ่ม 2 เป็นตัวช่วย, กลุ่ม 3 ตัดออกทั้งหมด

## 5 อย่างที่ควรเอามาใช้ต่อ (เรียงลำดับ) สำหรับงานเราโดยเฉพาะ

1. **faster-whisper (ไทย)** — ถอดเนื้อร้องจากเสียงเพลงเอง → ซับที่ตรงจังหวะจริง
   (ตอนนี้ซับถูก "ประมาณ" แล้ว K สั่งตัด เพราะลอยไม่ตรงคำร้อง). MIT, รันในเครื่อง,
   ไม่มีค่าใช้จ่าย. **ทำอันนี้ก่อน** — เพิ่ม watch-time และเหตุผลให้กดติดตาม.
2. **Ollama + โมเดลไทย (เช่น Qwen2.5)** — เขียนแคปชัน/คำอธิบาย/A-B hook ได้ไม่จำกัด
   ในเครื่อง ไม่มีโควตา ไม่มีบิล. ต่อกับ crosspost เพื่อทดลอง hook แบบมีข้อมูล.
3. **edge-tts (ทดสอบผ่านแล้ว)** — เสียงบรรยายไทย Neural สำหรับวิดีโอเล่าเรื่อง /
   พากย์ hook 2 วินาทีแรก (ที่ปรึกษาบอกว่า hook ตัดสินทุกอย่าง).
4. **PaddleOCR** — อ่านตัวเลขไทยจากภาพแดชบอร์ด (FB/TikTok/Shopee) แทนการเดาจาก
   HTML → ตัวเลข monitoring เชื่อถือได้ (บทเรียน "ตัวนับปลอม" จะหมดไป).
5. **ComfyUI/diffusers (ในเครื่อง)** — ปกคุณภาพสูงขึ้น; แต่กล่องเล็กอาจไม่มี GPU →
   ยังใช้ **Pollinations** เป็นหลักไปก่อน.

## ตรงไหน AI ฟรียังไม่ดีพอ — อย่าเสียเวลา

- **เพลงร้องไทยคุณภาพวางขาย**: ยังไม่มีโมเดลฟรีที่ทำได้ (ACE-Step ทดลองได้ แต่ไม่พอ
  สำหรับปล่อยจริง + เสี่ยงลิขสิทธิ์) → ใช้เพลงที่เราสังเคราะห์เอง (engine เดิม)
- **วิดีโอยาว/ตัดต่ออัตโนมัติเต็มรูปแบบ**: งานหนัก ควรใช้ FFmpeg ที่เขียนเอง
- **ออกแบบตัวอักษรไทยบนภาพ**: อย่าให้โมเดลเขียนไทย (สะกดผิด) — ใช้ PIL ทับข้อความเอง
  (มีใน `ai_covers.py` แล้ว)
