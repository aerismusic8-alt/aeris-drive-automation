มันคือศิลปะ"* เอกสารนี้คือหลักคิด + แผนที่ทำได้ฟรี ไม่ผิดกฎ.

## 2. ศิลปะของการทำให้กดติดตาม — สมองคนดูตัดสินใน 3 วิ

คนดูไม่ "อ่าน" เพจ — เขา **รู้สึก** แล้วตัดสิน. ลำดับที่ตากวาด:

1. **ปก** → "นี่คือที่สำหรับฉันไหม?" (อารมณ์/สวย/มืออาชีพ)
2. **รูปโปรไฟล์ + ชื่อ** → จำได้ไหม ไว้ใจได้ไหม
3. **Bio** → ให้อะไรฉัน? (สัญญา)
4. **จำนวนผู้ติดตาม** → คนอื่นคิดว่าดีไหม (proof)
5. **โพสต์บนสุด/ปัก** → ของจริงเป็นยังไง
6. **ปุ่มติดตาม** → กด

**สูตร 4 อย่างที่ทำให้กดติดตาม:**
- **ความรู้สึก (Feeling)** — คลิปที่เพิ่งดูทำให้ *รู้สึก* บางอย่าง (เศร้า/คิดถึง/อบอุ่น)
- **คำสัญญาว่ามีต่อ (Promise)** — "เพลงใหม่ทุกวัน" → กดติดตามแล้วได้อีก
- **หลักฐานสังคม (Proof)** — เห็นคนอื่นดู/ถูกใจ/ติดตาม
- **แรงต้านน้อย (Low friction)** — 1 ปุ่ม 1 เหตุผล ชัด ๆ

**หัวใจ:** คนไม่ติดตาม "ช่อง" — เขาติดตาม **ความรู้สึก** ที่อยากได้ซ้ำ.
เพจต้องเป็น *ที่เดียว* ที่ให้ความรู้สึกนั้น **สม่ำเสมอ**. เลือก "ความรู้สึกเดียว"
แล้วย้ำทุกอย่าง (ปก + bio + โพสต์ปัก) ให้ตรงกัน.

## 3. แผนแก้โปรไฟล์ (มุมคนดู) — ฟรี ทำจากเดสก์ท็อป

1. **ปักโพสต์ "ประตูหน้า"** — โพสต์ต้อนรับที่บอกว่าที่นี่มีอะไร:
   *"🎧 ยินดีต้อนรับ — เพลงไทยเพราะ ๆ ใหม่ทุกวัน · ร้องตามได้
   กดติดตามไว้ ไม่พลาดเพลงใหม่ 👇"* (ปักไว้บนสุด)
2. **เขียน Bio ใหม่ให้ "รู้สึก"** — เปลี่ยนจากบอกสินค้า เป็นบอกอารมณ์:
   *"🎵 เพลงไทยไว้ฟังยามเหงา คิดถึง ก่อนนอน · ใหม่ทุกวัน · คาราโอเกะร้องตามได้
   ▶️ ฟังเต็มที่ YouTube @aerismusicth"*
3. **ปกให้สื่ออารมณ์เดียว** — ภาพสวย + ข้อความสั้น "เพลงไทยเพราะ ๆ ใหม่ทุกวัน".
4. **ปุ่ม CTA** → "ติดตาม" หรือลิงก์ YouTube.
5. **End-card ทุกคลิป** — 3 วิสุดท้ายขึ้น *"กดติดตาม 👉 เพลงใหม่ทุกวัน"*
   (ศิลปะของการ "ขอ" ให้สวย ไม่ใช่โฆษณา).

## 4. ไอเดียให้คน "วิ่งมา" ติดตาม (ฟรี, ไม่โดนแบน)

เรียงตามแรง × ความปลอดภัย:

| # | ไอเดีย | ทำไมได้ผล |
| --- | --- | --- |
| 1 | **Hook 3 วิแรก** ให้ *รู้สึก* ทันที (เสียง/ภาพ/คำ) | คนเลื่อนผ่านเร็ว — 3 วิแรกคือทั้งหมด |
| 2 | **จัดฟอร์แมตมีชื่อ** เช่น "เพลงเศร้าประจำวัน" | คนจำได้ รอได้ → กดติดตามเพื่อรอ |
| 3 | **คำถามชวนคอมเมนต์** "เพลงนี้เตือนถึงใคร? พิมพ์ชื่อไว้" | คนคอมเมนต์ = โอกาสติดตามสูงมาก |
| 4 | **คาราโอเกะร้องตาม** = จุดต่างจากช่องเพลงอื่น | คนอยากกลับมาร้อง |
| 5 | **ปล่อยเวลาเดิมทุกวัน** | สร้างนิสัย + algorithm ชอบ cadence |
| 6 | **ตอบทุกคอมเมนต์** | คอมเมนต์น้อย ทำได้หมด = engagement พุ่ง |
| 7 | **Cross-promote 4 ผิว** (bio ชี้หากันไปมา) | คนเจอที่หนึ่ง → เจออีกที่ |
| 8 | **ส่งต่อ (Share bait) จริงใจ** "ส่งให้คนที่คุณคิดถึง" | ฟรี; Reels ที่คนแชร์ = reach ระเบิด |
| 9 | **ปักคลิปที่ปังสุด** (ไม่ใช่ใหม่สุด) | ประตูหน้าที่ดีที่สุด |
| 10 | **เชิญเพื่อนที่มีจริง** (FB Invite friends ครั้งเดียว) | เริ่มจากเครือข่ายตัวเอง |

**ห้ามเด็ดขาด (โดนแบน/ผิด Rule #1):**
- ❌ **Mass DM / ทักคนที่ไม่ได้ขอ** = spam → จำกัด/แบน
- ❌ **ซื้อผู้ติดตาม/วิว** = ผิดกฎ → แบน
- ❌ **Boost / โฆษณา** = เสียเงิน = ผิด Rule #1
- ❌ **สแปมกลุ่ม/คอมเมนต์คนอื่น** = โดนธง

## 5. ตัวชี้วัด (ดูอะไรถึงรู้ว่า "ศิลปะ" ได้ผล)

- **กดติดตาม / วิว (follow-through rate)** — ยิ่งสูง = ประตูหน้าดี
- **% ดูจบ 3 วิแรก** — hook ดีไหม
- **แชร์ / วิว** — เนื้อหาควรค่าแก่การส่งต่อไหม
- **คอมเมนต์ / วิว** — กระตุ้นบทสนทนาได้ไหม

อ่านจริงทุกวันผ่าน `grow.py status` + `report.py`; อ่านไม่ได้ = UNKNOWN.
