## 3. แผนเร่งรายได้ — 4 ระยะ พร้อมเกตวัดได้

### ระยะ A — ปล่อยให้เต็มเพดานทุกผิว (ทำเองได้ทันที) 🟢

เป้า: **ไม่ให้คิว 92 ชิ้นนอนนิ่ง** และให้คลิปสินค้าแตะคนจริง

- [ ] TikTok 4/วัน · Facebook 4/วัน (เพดาน `DAILY_CAP=4`, ห่าง 20 นาที)
- [ ] YouTube `ax-music-release` 6/วัน (โควตา 10,000 units ÷ 1,600)
- [ ] คลิปสินค้า **≥1 อัน/วัน** แทรกกับคลิปเพลง (อัตราส่วน 60/25/15)
- **เกต A:** posted ≥ 8/วัน ติดกัน 3 วัน · ไม่มี run แดงเพราะ session
- **เวลาถึงเป้า:** คิว 92 ชิ้นหมดใน **~11 วัน** ที่ 8/วัน

### ระยะ B — เพิ่มการมองเห็น 2–8 เท่า (ตัวชี้ขาดรายได้) 🔴 ตัวที่ต้องทุ่ม

นี่คือระยะที่ตัดสินว่ารายได้จะเกิดหรือไม่. 4 คันโยกฟรี เรียงตามแรง:

1. **Hook 3 วินาทีแรก.** Shorts จะถูกตัดสินใน 3 วิแรก. คลิปที่ขึ้นต้นด้วย
   "คนดีที่จากไป" (ชื่อเพลง) ไม่บอกว่าคนดูจะได้อะไร. ต้องขึ้นด้วยคำถาม/ประโยชน์.
   - งาน: เขียน hook ใหม่ 20 อัน ให้คลิปสินค้า
     ("หูฟัง 300 บาท ต่างจาก 3,000 ยังไง" ดีกว่า "3 จุดที่ควรดู")
2. **จำนวน.** อัลกอริทึมให้รางวัลกับความสม่ำเสมอ. 8/วัน ดีกว่า 3/วัน.
3. **แฮชแท็กเฉพาะกลุ่ม + เสียงที่กำลังมา.** TikTok ให้ reach กับคลิปที่ใช้
   เสียงเทรนด์. ต้องดึงรายการเสียงเทรนด์รายวัน.
4. **YouTube ยาว = watch-hours.** Shorts แทบไม่สะสม 4,000 ชม. เพลงยาว 3–5 นาที
   ที่คนฟังจบคือทางเดียว. + playlist ให้ฟังต่อเนื่อง.

- **เกต B:** views/สัปดาห์ เพิ่มจาก ~1,300 เป็น **≥4,000** ภายใน 21 วัน
- **ถ้าไม่ถึง:** แปลว่า hook ยังไม่ทำงาน → กลับไปแก้ข้อ 1 ไม่ใช่โพสต์เพิ่ม

### ระยะ C — เปลี่ยน view เป็นคลิก (ทำคู่ขนาน) 🟡

ทราฟฟิกที่มีอยู่จะเสียเปล่าถ้าไม่มีทางกด:

- [ ] ลิงก์ affiliate ใน **bio ทุกผิว** (ไม่ใช่แค่แคปชั่น)
- [ ] **pinned comment** ใต้ทุกคลิปสินค้า (คนกดคอมเมนต์มากกว่าคำอธิบาย)
- [ ] เปิดเผย affiliate disclosure ทุกครั้ง (COMPLIANCE บังคับ)
- [ ] **ห้ามอ้างว่าทดลองใช้** — เราไม่ได้ทดลอง; เป็น buying guidance ไม่ใช่รีวิว
- **เกต C:** คลิก Shopee > 0 ภายใน 14 วัน · คลิก/1,000 views ≥ 5

### ระยะ D — วัด → แก้ → ทำซ้ำ (ทุกวัน) 🟡

- รัน `social_stats.py` + `market.py --channel ch3` ทุกวัน เก็บลง `history.jsonl`
- สัปดาห์ละครั้ง: คลิปไหน views สูงสุด → ทำแบบนั้นซ้ำ. คลิปไหนเงียบ → เลิกทำแบบนั้น
- **เกต D:** มีข้อมูล ≥ 14 วันพอตัดสิน "อะไรได้ผล" (ตอนนี้ยังไม่มี)
