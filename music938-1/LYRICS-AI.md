## วิธีแก้

`scripts/ai_lyrics.py` ให้ **Gemini web** (ฟรี ไม่ต้องล็อกอิน) เป็นคนเขียนเนื้อร้อง
ภายใต้กติกาเข้ม:

1. บรรทัดละ **8 พยางค์พอดี** (พยางค์ไทย = 1 เสียงสระ)
2. 1 บรรทัด = 1 ลมหายใจ
3. ตัดบรรทัดตรงขอบวลีธรรมชาติ
4. สัมผัสท้ายบรรทัด ก-ข-ก-ข
5. บรรทัดแรกของทุก chorus = ฮุกที่ร้องซ้ำได้
6. ภาษาเรียบง่าย ไม่ประดิษฐ์คำ

```bash
python3 scripts/ai_lyrics.py --slug 04-saeng-chao-wan-mai          # ดูทาง stdout
python3 scripts/ai_lyrics.py --slug 04-saeng-chao-wan-mai --write  # เขียนทับจริง
```

ต้องมี cloud desktop (CDP 9222) ขึ้นอยู่ — Gemini ไม่ต้องล็อกอิน แต่ต้องมีเบราว์เซอร์

## บทเรียนการขับ Gemini

- ใช้ `keyboard.insert_text` **ไม่ใช่** `keyboard.type` — พรอมป์หลายบรรทัดพิมพ์ `\n`
  แล้ว `type` จะกด Enter = ส่งข้อความตั้งแต่บรรทัดแรก (Gemini เลยตอบ "ขอรายละเอียดเพิ่ม")
- ตัดคำตอบหลังคำว่า **"Gemini said"** เพราะพรอมป์เองมีแท็ก `[verse]`/`[chorus]`
  ถ้าเริ่มจากแท็กแรกจะได้พรอมป์ที่ echo กลับมา
- โมเดลชอบต่อท้ายบรรทัดด้วย `(8)` — ล้างออกก่อนเขียนไฟล์ ไม่งั้น Flow จะร้องออกมา
