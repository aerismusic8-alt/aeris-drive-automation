# TRASH — AKATH / AX Quarantine

Purpose: quarantine obsolete, duplicate, superseded, or suspect repository artifacts without immediate hard deletion.

Rules:
1. Active/canonical implementations stay outside TRASH.
2. Suspect or obsolete artifacts go here with their original path preserved in the manifest.
3. Before creating a replacement for a blocked/missing component, search TRASH first and evaluate whether a reusable implementation exists.
4. TRASH is not an execution path and must not be imported as active runtime code.
5. Restore/reuse requires verification against the current canonical architecture and evidence.
6. Do not remove historical evidence solely for cleanup.

Canonical local execution remains AX_PC_NODE.ps1 unless verified evidence establishes a better existing implementation.
