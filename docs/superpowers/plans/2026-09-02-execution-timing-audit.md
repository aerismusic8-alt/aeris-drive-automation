# ระบบจับเวลาและหลักฐานเวลาการทำงาน — แผนดำเนินการ

> **สำหรับผู้ปฏิบัติงาน:** ใช้แนวทางพัฒนาตามขั้นตอนทดสอบก่อนพัฒนา และตรวจสอบหลักฐานก่อนประกาศผล

**เป้าหมาย:** ทำให้ทุกงานที่ระบบอ้างว่าเริ่มหรือเสร็จสามารถระบุวันเวลาได้ชัดเจน และคำนวณเวลาที่ใช้จริงเทียบกับเวลาเป้าหมายเพื่อวิเคราะห์ความเร็ว คอขวด และความเสี่ยงได้

**สถาปัตยกรรม:** เพิ่มชั้นบันทึกเวลาการปฏิบัติงานแยกจากเวลารอบประมวลผล โดยแต่ละงานมีเวลาเริ่มจริง เวลาจบจริง เวลาหยุด/ทำต่อ เวลาที่ใช้จริง และหลักฐานอ้างอิง การเริ่มงานต้องเกิดจากเหตุการณ์ที่ตรวจสอบได้ ไม่สร้างเวลาเริ่มย้อนหลังโดยไม่มีหลักฐาน

**เทคโนโลยี:** PowerShell, JSON, GitHub Actions/บันทึกการทำงานของระบบ

**ข้อกำหนด:** `AX_TASK_REGISTRY.json` และกฎการติดตามเวลาปัจจุบัน

## ข้อกำหนดหลัก

- เวลาเริ่มรอบรวมไม่ถือเป็นเวลาเริ่มงานรายงาน
- เวลาเริ่มจริงต้องมีหลักฐาน
- เวลาใช้จริงต้องคำนวณจากเวลาเริ่ม/หยุด/ทำต่อ/จบ
- งานที่ยังไม่เริ่มต้องระบุว่าไม่มีเวลาที่ใช้จริง
- ต้องแยกเวลาเป้าหมายออกจากเวลาจริง
- ต้องคำนวณสถานะเร็วกว่า/ตามแผน/ช้ากว่า
- หากเกินเกณฑ์ต้องสร้างสัญญาณให้วิเคราะห์คอขวด
- หลักฐานต้องเก็บวันเวลาและแหล่งที่มาเพื่อวิเคราะห์ย้อนหลัง
- ห้ามเปลี่ยนสถานะเป็นเสร็จจากการคำนวณเวลาเพียงอย่างเดียว ต้องมีหลักฐานผลลัพธ์และการตรวจสอบ

## งาน

1. เพิ่มชุดทดสอบสำหรับการคำนวณเวลาและการจัดสถานะความเร็ว
2. เพิ่มตัวประมวลผลบันทึกเวลา
3. เพิ่มฟิลด์เวลาในทะเบียนงานและรูปแบบหลักฐาน
4. บันทึกการเริ่มจริงของงานที่เริ่มปฏิบัติแล้วเท่านั้น
5. ตรวจสอบผลด้วยการทดสอบและหลักฐานจากระบบ
6. อัปเดตรายงานให้ระบุเวลาที่ใช้จริงและสัญญาณความล่าช้า
