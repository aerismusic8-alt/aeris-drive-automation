# TITLE: เกร็ดวิทยาศาสตร์
# THEME: weather
ทำไมฟ้าผ่าจึงเกิดก่อนที่เราจะได้ยินเสียงฟ้าร้อง?

เพราะแสงเดินทางได้เร็วกว่าเสียงมาก แสงเดินทางราว 300,000 กิโลเมตรต่อวินาที ส่วนเสียงในอากาศไปได้เพียงประมาณ 340 เมตรต่อวินาที

เราจึงเห็นแสงฟ้าแลบก่อน แล้วเสียงฟ้าร้องตามมาทีหลัง ถ้านับวินาทีระหว่างสองอย่างแล้วหารด้วยสาม จะได้ระยะทางคร่าว ๆ เป็นกิโลเมตร
