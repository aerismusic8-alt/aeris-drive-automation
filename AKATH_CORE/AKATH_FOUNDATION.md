# AKATH Foundation

Status: CLEAN_START

AKATH is being rebuilt from zero. No historical workflow, task, dashboard, execution system, or mission is current unless explicitly created and verified after this reset.

## Authority
- K = Final Authority
- AX = Executive Management and Orchestration System
- A MASTER BRAIN = durable knowledge and accumulated experience only

## Core rule
A MASTER BRAIN may inform design and recovery, but it cannot create current tasks or current operational state.

## Canonical execution direction
K → AX Executive → AX Runtime/Supervisor → Canonical Job State → Dispatcher → PC1 Main → Specialist → Execute → Evidence → Verify → Recovery/Next Job

## Completion gate
A job is DONE only when:
1. execution produced an actual result;
2. evidence is persisted and linked to the same job identity;
3. verification passes.

## Time governance
Every active job must have a trusted start time, deadline, milestones, and completion criteria. A missed deadline triggers cause analysis and corrective action. A deadline must never be silently extended.

## Clean-start rule
Do not restore or merge historical operational structures into AKATH. Reuse experience, not old system state.
