## aeris938-2 — the conversion gap is the whole revenue problem

Live state (AR measured): TikTok 377 views/7d, YouTube 2,182/28d, FB 38/28d — but
followers stuck at 1 on FB and TikTok, and Shopee **0 clicks / 0 orders / 0
commission**. Views are not the blocker; conversion is.

Root cause, found by reading the live links: **every outbound Shopee link
pointed at the storefront homepage.** A viewer who tapped landed on a generic
Shopee front page with nothing to buy, so nobody did. The second shape: the
affiliate line sat at the *bottom* of the YouTube description (past the "Show
more" fold) and at the end of the FB/TikTok captions.

### Environment facts re-confirmed

- **The write token has no `workflow` scope.** A push touching
  `.github/workflows/*.yml` is rejected even with `AX_GH_TOKEN`
  (`refusing to allow an OAuth App to create or update workflow ... without
  workflow scope`). Put the logic in a `.py` the workflow already runs
  (`daily_release.py`), not in the `.yml`. A rejected push leaves nothing
  behind, but a *commit* that includes a `.yml` change keeps blocking every
  later push — `git checkout FETCH_HEAD -- <file>` then `git commit --amend`.
- YouTube Data API is still 403 `quotaExceeded` at 03:30 UTC (resets 07:00 UTC).
- A fresh pod lacks `ffprobe`; install it (`scripts/setup-pod.sh` / apt) before
  the full test suite.
- `aeris938-2` is a *tracking/reporting* repo (channel.json + report.py +
  grow.py); the executable rails live in `music938-1`.
