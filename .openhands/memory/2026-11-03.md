### Environment facts re-confirmed

- **The write token has no `workflow` scope.** A push touching
  `.github/workflows/*.yml` is rejected even with `AX_GH_TOKEN`
  (`refusing to allow an OAuth App to create or update workflow ... without
  workflow scope`). Put the logic in a `.py` the workflow already runs
  (`daily_release.py`), not in the `.yml`. A rejected push leaves nothing
  behind, but a *commit* that includes a `.yml` change keeps blocking every
  later push — `git checkout FETCH_HEAD -- <file>` then `git commit --amend`.

- A fresh pod lacks `ffprobe`; install it (`scripts/setup-pod.sh` / apt) before

  grow.py); the executable rails live in `music938-1`.

bootstrap's "restore skipped" line (the 401 is `ax_vault.ensure_anchor()`'s
automation-list path, not a dead vault).
