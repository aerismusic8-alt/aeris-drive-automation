### Bug 1 — the crosspost rail could not record its state (51ac8c18)
`.gitignore` carried a **duplicate bare `music938-1/work/`** line (added in
`a9a3cf7a`, in the "scratch" block near line 85) on top of the intended
`music938-1/work/*` + `!...` re-includes. A trailing-slash rule ignores the whole
*directory*, and git cannot re-include a file inside an ignored directory, so every
`!music938-1/work/*.json` was dead. `git add music938-1/work/crosspost-state.json`
then exits 1 with "The following paths are ignored by one of your .gitignore files:
music938-1/work" — which failed the rail's commit step (run 42317640960 step 8)
*after every run that actually posted*. Diagnose this class with
`git check-ignore -v --no-index <file>` (a plain `check-ignore` says "not ignored"
because the file is tracked, which is what hid it). Guard: `test_state_files_are_addable`.
