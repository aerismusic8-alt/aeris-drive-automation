### ⚠️ The thing that cost the most time: `BUILD_REF` lies, and the branch is what ships

`AX PC1 Roblox Publish` logs `BUILD_REF=main`, and it is easy to read that as "main was
published". It was not. `AX_PC_CONTROL/pc1-roblox-build.ps1` has
`$BRANCH = 'ax-arena-roblox-game'` **hard-coded**, so the *script* is fetched from the
ref you passed while the *code it builds* always comes from that branch:

```
BUILD_REF=main
HEAD is now at 967753a Temporary: dump both universe objects from the live-state job
Building project 'AXArena'
SOURCE_BLOCKS=39   SCRIPT_INSTANCES=39
```

`SOURCE_BLOCKS=39` = the branch's `roblox/` (32 shared + 5 client + 2 server). `main`'s
`roblox/` has 28 files (24 + 2 + 2). **The two refs are different games.** They diverged
at `6f2e48b` (2026-10-19); `main` is 35 ahead / 135 behind the branch. `main` holds the
newer Ragnarok-systems work (`Config.Version = "1.0.0"`); the branch holds a bigger tree
(`Config.Version = "1.0.1"`, plus `roblox-garden/` and `breachline/`) and it is the one
players get.

Consequence: editing `roblox/` on `main` changes nothing that is live. Confirm which tree
owns a file before promising a change reaches players.
