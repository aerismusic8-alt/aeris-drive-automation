Music", both into reusable libraries. What I actually measured:

promise keyless Gemini image generation.

**Google Flow (flow.google.com)** — the real product page. Free tier is real:

Agent, text-to-video, 2K image upscaling. Paid: AI Plus $4.99, AI Pro $19.99, Ultra $99.99.
Landing page is public but generation requires a Google Account.

**Flow Music is genuine and is a real Google product** (I checked the hard way, because a

- `flowmusic.google` -> 301 -> `flowmusic.app` -> 308 -> `www.flowmusic.app`
- TLS cert for `flowmusic.google` is `CN=flowmusic.google`, issuer **Google Trust Services**

  `client_id=1032626174130-533micbc9tgsei76mqhtguq07lpoe4je.apps.googleusercontent.com`,
  `redirect_uri=https://sb.flowmusic.app/auth/v1/callback`,
  scope `email profile .../auth/subscriptions.thirdparty.googleone.eligibility`
- Sign-in is **Google-only** (no email/password form of its own)

## aeris938-1: Thai story -> karaoke episode pipeline (built + verified)

The `flowmusic.app` finding matters most: **it is not Google.** Chain verified by TLS:
`labs.google/fx/tools/music-fx` -307-> `flowmusic.google` (Google Trust Services) -301->
`flowmusic.app` -308-> `www.flowmusic.app` (Cloudflare 104.26.3.189, Let's Encrypt).
Network capture of the app page: contacts only fonts.googleapis.com, fonts.gstatic.com,
static.cloudflareinsights.com, googletagmanager.com, ph.flowmusic.app — **no Google API.**
It is a Next.js bundle that brands itself "Google Flow Music". Treat as third-party; the
operator signs in themselves, the agent must not fill a credential there.

**Sandbox can be given a real desktop.** `sudo` works, apt works. Installed:
xvfb, x11vnc, novnc, websockify, openbox, fonts-thai-tlwg, ffmpeg, plus pip
playwright/Pillow/numpy/pythainlp/edge-tts/pytest. `desktop.sh up` brings up
Xvfb:99 1600x900 + openbox + x11vnc:5900 + websockify:12000 + headful Chromium with
`--remote-debugging-port=9222 --user-data-dir=~/.aeris938/chrome-profile`.
**noVNC reaches the outside** via the work host: `https://work-1-<host>/vnc.html` -> 200,
and a raw websocket upgrade to `/websockify` returns 101 Switching Protocols. That is the
operator's sign-in path: log in once in noVNC, agent then drives the same session over CDP.
`playwright.chromium.connect_over_cdp("http://127.0.0.1:9222")` works.

**Verified numbers from this build** (measured, not assumed):
- edge-tts Thai voices: only `th-TH-NiwatNeural` (M) and `th-TH-PremwadeeNeural` (F).
  Thai emits SentenceBoundary; 8/8 and 7/7 lines matched to boundaries exactly.
- Two-pass `loudnorm` is mandatory: one pass gave **-21.1 LUFS** against a -17 target;
  two-pass with `linear=true` + measured_I/TP/LRA/thresh/offset hit **-17.1**.
- `PIL features.check("raqm")` is **True** in this sandbox, so Thai tone marks shape
  correctly; `covers.py` refuses to run without it rather than rendering broken text.
- ffmpeg 7.1.5 has libass (`ass`, `subtitles` filters), so karaoke burns in correctly.
- Karaoke highlight verified at pixel level: yellow (unsung) 5271->407 px while white
  (sung) 713->5411 px across one cue. ASS colours are &HAABBGGRR: primary=white (sung),
  secondary=&H0000D7FF=yellow (unsung).
- ffmpeg input indices shift when an optional `-i` is omitted -> "Invalid input file
  index". Count inputs explicitly. `-vsync vfr` + `-r` is a hard error; use `-fps_mode cfr`.
- `flowmusic.app` signed out has **0 input elements**; a missing composer is the login
  signal, so detect the landing copy instead of waiting for a locator to time out.
