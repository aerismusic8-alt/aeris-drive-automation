# 2026-11-11 — AR working log

## Facebook rail outage — diagnosed, fixed, verified

**Symptom:** `AX Music Crosspost (FB Reels + TikTok)` run 42988731218 (08:39Z) failed
with 134 posts queued; a heartbeat run had also gone red.

**Root cause — TWO independent failures at once, easy to conflate:**
1. **Graph token rejected at the account level.** `API access blocked`, OAuthException
   200, since 2026-11-08. A never-expiring System User token can still be revoked.
   Only the owner can mint a new one (App Dashboard). A fresh token from the *same*
   app would likely be rejected too — the block is app/account-level.
2. **Browser cookie session dead.** Facebook served the logged-out page while still
   holding `c_user`/`xs`, so a cookie-presence check read "ok" for a dead session.
   `login_vault restore` reported `SESSION REJECTED`. This is the one AR can fix.

**Fix applied:**
- Held the advisor consultation (`ops/consult.py`) — quorum PASS (duck + pollinations).
  Consensus: don't chase FB hard, focus the 3 working surfaces, one owner action.
  Then went further than the advice because the browser route *was* revivable.
- Logged in over CDP with the vaulted password (`axsecrets:fb-password`, 9 chars).
  The remembered-account chooser ("Continue as Aeris-Ak Akath") leads to a Meta-account
  password form; submitted once → `c_user` set, feed visible, **no checkpoint**.
- `ops/login_vault.py save` (271 cookies, FB now SIGNED IN on restore).
- Pushed a fresh `AERIS_STORAGE_STATE_B64` (28 KB blob) via the workflow token.
- Dispatched crosspost run 43013550260 → **posted a FB Reel**
  (`facebook.com/reel/1818815976028171`), all steps green.

**New durable tool:** `ops/fb_relogin.py`
- `--check` reports the live session; default revives it (single attempt, no retry
  loop — retries trigger a checkpoint) and saves to the vault.
- `--push-secret` also refreshes `AERIS_STORAGE_STATE_B64`.
- Covered by `test_fb_relogin` in `music938-1/tests/run.py`.

**Second bug found while testing:** `music938-1/tests/run.py` called an undefined
`note()` helper at the "no sfizz bank on this pod" branch, crashing the whole suite
(`NameError`) on any bare pod. Added the helper. Suite now completes: 1738 passed,
5 failed (the 5 are environmental — no songs built on a fresh pod; themes can't
reach their floor). Not caused by the change.
