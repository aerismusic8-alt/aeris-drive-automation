- **`music938-1/work/affiliate-products.json` was gitignored and had never been
  committed.** A fresh pod therefore had no cards: `make_affiliate_short` could
  not run, and `tests/run.py` died with `IndexError` on an empty product list —
  which reads as "the suite is broken", not "a file is missing". It is now
  tracked, with the same rationale as the other `work/` state files.
  **Recovery route for a lost work file:** the conversation event log under
  `/workspace/conversations/<id>/events/event-*.json` still holds the

  key lived on the ephemeral overlay. The working write path is the classic PAT

  `Authorization: token …` header. The sandbox `GITHUB_TOKEN` is read-only (403).
- **`ffmpeg`/`ffprobe` are at `/workspace/ax-tools/bin` (symlinks to
  `/workspace/ax-tools/ffmpeg/...`).** Add that dir to `PATH` or several tests
  fail (`compile_album.duration` → `FileNotFoundError: ffprobe`), which looks
  like a code bug but is just a missing binary.
- **YouTube quota is 6 uploads per Pacific day.** `release-state.json` showed
  6/6 spent on 2026-11-05, so the affiliate clips go out at the next 07:00 UTC

## Growth stall — advisor verdict + the fixes (2026-11-05)

Brief `aeris938-2/work/consult-brief-growth-stall-2026-11-05.md`, panel 3/3
(duck, duck-claude, duck-oss), 423 s each. Unanimous: the likely cause is
**repetitive Shorts** — 25 clips from 5 songs, one karaoke-chorus format, titled
"part N of 3" — then weak hook. The paused TikTok/FB rails are a *separate*
distribution failure; falling views are **not** evidence of duplicate-content
suppression. 6/day is not harmful, it is a bad test: run one distinct Short a day
for 7 days, then compare. Keep the lyric format, change the series and the clips
("ร้องต่อไหม?"). One metric: subs per 1,000 YT views; test target 10 net in 7 days.
The panel also corrected the quota brief: `videos.insert` is a **100/day bucket**,
not 1,600 units of the 10,000 pool — so cadence is a choice, not a wall.

Shipped in `1e1aaf0b` (pushed): `plan()` interleaves one chorus per song;
per-hook `HOOK_TITLES`/`HOOK_ANGLES` replace "(ท่อนที่ N)"; `crosspost.caption()`
mirrors it and `refresh_captions()` rebuilds affiliate items instead of crashing;
`describe_affiliate()` reordered. 688 tests pass.

Second panel, `consult-brief-affiliate-link-fold-2026-11-05.md` (3/3, 424 s):
**a URL in a Short's description or a pinned comment is not tappable** — so the
above-fold lines carry the *disclosure* + a CTA to the **channel profile link**,
with the tracked `s.shopee.co.th` URL kept as a copyable fallback for attribution.
YouTube allows affiliate links but warns that *excessive* affiliate posting on a
dedicated account can hit the spam policy — keep each card genuinely distinct.

Gotchas that cost time:
- `ops/consult.py --file <brief>` takes ~7 min with duck in the quorum; run it
  backgrounded and poll, don't block.
- The KV read of `axsecrets:gh-workflow-token` needs `OPENHANDS_API_KEY` set
  (`Authorization: Bearer`); without it the API returns 401. The value is a dict:
  `{"token","login","scopes","note"}` — read `["token"]`.
- Pushing a workflow file needs the **classic PAT** (`repo,workflow`); the
  app-minted token is refused with "refusing to allow an OAuth App to create or
  update workflow … without `workflow` scope".
- The pod that ran this had a fresh remote ahead of the clone: `git fetch` +
  `rebase origin/main` before pushing, or the push is rejected.
