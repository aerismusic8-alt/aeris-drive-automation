## Trap hit (do not repeat)

`python3 AKATH_CORE/add_roblox_goals.py` is **not** safe to run against the current
registry: it does a full `update` from a hard-coded September snapshot, so it
**reverted newer Roblox evidence** (published_versions, live ids, the corrected
blocker text, the "Content May Vary" label). Recovered by restoring from the
pre-run backup and re-running only `reconcile_growth_scope.py`. Lesson: an
"idempotent" seed script that hard-codes a whole record will clobber live updates
to that record — make it merge, or don't run it after the record has moved on.
