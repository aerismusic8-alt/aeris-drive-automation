
## music938-1: the "silent syllable" was a measurement artifact, not a defect (2026-10-29)
Song 04 reported 130/252 silent syllables, then after the clip fix still "1 silent" at
22.683s. That last one was FALSE. Cause: the report compared the song master against the
karaoke master window by window. The backing ducks under the voice (`_duck`), so at a
*loud* note the karaoke is as loud as the song and the difference test sees nothing —
a loud note and a missing note look identical. Proof: the raw vocal buffer at that
timestamp has rms 0.156 / peak 0.883, i.e. the note is the loudest thing in the mix.
**Fix:** `make_song.py` now records each sung note's own `rms` (measured on the synth clip
before mixing) into `timing.json`; `report.py::vocal_present` reads that field, and
`tests/run.py` asserts `every sung note has audio` for all 20 songs. Never infer vocal
presence by differencing two mixes when a duck is in the chain. 404 tests pass.
Also: `audio.normalize(backing, 0.11)` left the instrumental peaking at 1.0 (drum hits);
now clamped to 0.95 before the 16-bit write. Song 04: -14.2 LUFS song vs -17.4 karaoke.

## Org-level skill loading: the exact mechanism (verified 2026-10-29)
K said "ทำแล้ว" (created the repo) but created **`.agent`** (singular); OpenHands
wants **`.agents`** (plural). Renaming is blocked: the sandbox token 403s on repo
create, repo rename, and every push — including to repos that already exist, so it
is not an installation-scope issue, it is a genuinely read-only token.

Verified by experiment (not from docs):
- The org loader clones the repo and reads **`<clone>/skills/<name>/SKILL.md`** —
  `skills/` at the repo **root**, NOT `.agents/skills/`. Proved with a local git repo.
- The repo may be **public**; no token needed to read it.
- `POST /api/skills` accepts an `org_configs` array

  arbitrary repo name — but that config is per-request. A `PATCH /api/settings` with

  `registered_marketplaces: []`). So there is no server-side global install route
  available to the agent.
- `POST /api/skills/install` → `~/.openhands/skills/installed/` (ephemeral overlay).

**Conclusion:** the only durable, agent-reachable install is (a) the repo copy at
`.agents/skills/` (git-tracked) + `scripts/install-agent-skills.sh` to restore the
