## AR's own social account — which ones it can self-create (2026-11-15)

K asked "AR สร้างบัญชีโซเชียลของตัวเองอะไรได้บ้าง" and then said "มีช่องทางไหนทำได้ทำเลย".
Exhausted the unattended-signup routes and **opened the one that works**.

**Answer:** only **Nostr** is openable unattended. Everything else is blocked:
- **Bluesky** — `bsky.social` AND every federated PDS (`selfhosted.social`,
  `eurosky.social`, `blacksky.app`) now return
  `InvalidPhoneVerification: Verification is now required on this server`.
  The lexicon still says `required:["handle"]`, so the phone gate is a
  server-side policy, not the protocol. (`ops/ar_bluesky.py` is written and
  ready for the day a phone-free PDS exists.)
- **Mastodon** — every open instance either blocks the mail.tm domain
  (`mastodon.social`, `mastodon.bida.im`: `E-mail address uses a disallowed
  e-mail provider`) or requires human application approval (`mastodon.uno`
  mails "we will review your application"). `password` grant is disabled →
  no unattended login anyway.
- **Lemmy** — all 15 probed instances `RequireApplication`.
- **Misskey** — 14 open (no captcha flag) instances found via
  `instanceapp.misskey.page/instances.json`, but **all 14 still enforce a
  captcha server-side** (turnstile/hcaptcha/recaptcha), plus one
  `SIGNUP_COUNTRY_RESTRICTED` (Japan only).
- **Google** — `google-account.json` exists, `status:
  blocked-device-verification` (email verified; stuck on
  `crossflowverification`, needs a real Android device / K taps QR once).

**Root blocker for the fediverse:** mail.tm has exactly one domain
(`fldubai.com`, checked `api.mail.tm/domains`) and it is on every disposable
blocklist. A non-disposable AR mailbox is the unblock — none is free + API-only
today.

**Opened: Nostr** (`ops/ar_nostr.py`). Identity = a locally-generated secp256k1
keypair, so there is no signup to block. Pure-Python BIP340 Schnorr (validated
against the official vectors) + bech32 npub; publishes signed kind-1 events over
`websocket-client` (installed via pip; add to bootstrap). First note accepted by
3/5 relays (`nos.lol`, `relay.primal.net`, `nostr.mom`) and **read back from
`nos.lol` to prove it is live**. npub:
`npub15km3dw0xx8kp0tazwslj3a4dr9xcqep39jhjwxnxwpvlx8mnapkq29ftuw` (view:
`njump.me/<npub>`). Keypair in `/workspace/ax-tools/ar-identity/nostr.json`
(mode 600). Registered in `ops/ar_accounts.py` (now 1 account).
