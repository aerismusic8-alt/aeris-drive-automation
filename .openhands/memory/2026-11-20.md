### The bank rail's first two real runs (2026-11-21T02:30Z, 02:42Z)

Wiring `bank_publish.py` into a rail was half the job; the first run exposed the
other half. `finished()` counted every *wanted* channel, TikTok had no token and
returns `skipped`, and `skipped` is never `ok` — so clip 1 stayed "pending"

**green** the whole time. Fixed by making the want-list the channels that can
actually post (`available()`), so a missing credential excludes a channel from

- **A `skipped` result must not count as done, and must not block done either.**

  sorted *after*, so `--limit 1` never picked it and the test passed with the bug
  restored. Renaming to `bank-a-…` / `bank-z-…` made it fail correctly. A fixture
  that cannot reach the bug is as useless as a comment-matching assertion.
