## Free image-to-video that actually works today

The five HF Spaces in `make_motion.py` were reported dead on 2026-11-19
("ZeroGPU runs limit exceeded"). **They recovered.** `wan777`
(`kulkas2pintu/wan777`) returned a 480x832 h264, 16 fps, 3.56 s clip in ~90 s,
**zero credits, no token**. Measured mean abs frame diff **8.06** — same range as
the 8.33 that the memory calls "real motion", against 0.77 for a zoomed still.

So the working free pipeline is: **Dreamina `seedream_4.0` still (8 credits) →
`make_motion.py` Wan HF Space (free) → motion clip**. Added `--image` /
`--out-dir` to `make_motion.py` so any still can be animated instead of only a
song cover; pinned by `test_motion_lane` (signature check, no network).
`ops/clip_standard.py` has no profile for 480x832, correctly: that is a raw
asset, and the lane that ships it must render 1080x1920 and be gated there.
