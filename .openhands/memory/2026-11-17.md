### The tool
`ops/trivia_reel.py` (new). Landscape counterpart of `ops/story_reel.py` (which is
vertical/horror). Reuses `thai_tts`, `stills_rail`, `footage_rail`, `branding`.
- `SPEC` dict holds every measured number; `music938-1/tests/run.py::test_trivia_reel`
  pins them so the standard cannot drift.
- Backgrounds: free Wikimedia Commons **footage** first (`footage_rail.search_video`),
  licence-checked stills as fallback. Footage clips are looped, scaled/cropped,
  **crossfaded 0.5 s** (no hard cut, like the reference).
- Audio: per-card edge-tts, concatenated with a 0.4 s gap, then **loudnorm −15 LUFS**.
- Scripts live in `scripts_trivia/*.md` (one card per blank-line block, `# TITLE:`
  and `# THEME:` headers). First sample: `scripts_trivia/sky-blue.md`.
- Standard documented in `docs/trivia-clip-standard.md`.

## The standard is a FLOOR (K follow-up, same day)
K: "อันนี้เป็นแค่มาตรฐานเริ่มต้นสามารถทำได้ ห้ามมาตรฐานต่ำกว่านี้เด็ดขาดในช่องของเรา"
So the standard is enforced, not just documented:
- `ops/clip_standard.py` — measures a finished clip (ffprobe + downscaled frames
  + ffmpeg loudnorm) and returns one row per rule; `check()` never raises,
  `assert_ok()` does. CLI exits non-zero on a fail.
- Calibrated on real files: good clip max consecutive-frame Δ = 6.5, stills+cut
  clip = 94.3, frozen frame = 0.0 → hard-cut limit 20, frozen floor 0.15. Loudness
  good −15.6 vs bad −22.7 LUFS → band −16.5..−13.5. Text px 1050 vs 480 → floor 120.
- `ops/trivia_reel.py` runs the gate after render and **deletes the MP4 + exits
  non-zero** on a fail, so a below-floor clip cannot be a finished artifact.
- `test_clip_standard_is_a_floor` pins the thresholds and builds a deliberately bad
  clip to prove the gate rejects it (wrong size / audio / frozen). Suite 2514/0.
- Recorded in `AGENTS.md` ("Clip quality — the floor"), `docs/trivia-clip-standard.md`,
  and the memory index. Raising a number is welcome; lowering one is forbidden.
